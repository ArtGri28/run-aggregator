# CLAUDE.md — проект «Бот ТГ»

Проектное исключение из глобальных правил Git. Действует **только внутри этого проекта** и не меняет глобальные настройки Claude Code (`~/.claude`).

Источник истины по проекту — `MVP.md` в корне (Git-политика: раздел 3.3). Планирование — `.planning/`.

## Git

Для этого проекта Claude и GSD **могут самостоятельно**:
- `git add`;
- `git commit`;
- обычный `git push` в настроенный remote текущего проекта.

**Запрещено без отдельного подтверждения владельца:**
- `git push --force`;
- `git push --force-with-lease`;
- `git reset --hard`;
- удаление веток;
- удаление remote;
- другие разрушительные git-операции.

**Теги:** пока не создавать.

**Сообщения коммитов** не должны содержать упоминаний:
- AI;
- Claude;
- GSD;
- использования ИИ.

Это относится и к строкам вроде `Co-Authored-By` с именем ИИ-инструмента.
