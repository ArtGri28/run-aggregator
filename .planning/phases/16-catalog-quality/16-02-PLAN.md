## Задачи

1. Префикс callback `q` по разделу 4 контракта: только кнопки заявки (`q:o:{id}`, `q:r:{id}:{буква}`, `q:x`); грамматика, устаревшие кнопки, один `answerCallbackQuery`. Кнопки предложения (`q:s`, `q:c`) — в 16-03.
2. Строка «Сообщить об ошибке» в карточке (C-1) — во всех местах, где строится клавиатура карточки; без группы поддержки и без администраторов строки нет (уточнение контракта).
3. Экраны R-1…R-7 и сообщение G-1 точно по контракту: проверки доступности и даты старта — в боте до вызова хранилища; доставка в группу либо личными сообщениями администраторам (D-07) с обработкой отказов Bot API по образцу поддержки; при сбое доставки заявка удаляется (`DeleteReport`).
4. Очистка заявок и предложений старше 90 дней — шаг `do(...)` в `Notifier.chores`.
5. Эталоны: 23 эталона карточек из раздела 9 — по одной добавленной строке, правка вручную по таблице контракта (не перегенерацией); новые эталоны сценария S-54. Сумма эталонов до и после — в SUMMARY.
6. Тесты: сценарий S-54 (`TestS54Report`), грамматика `q:`, предел, повтор, недоступный и прошедший старт, слитое событие, без группы — администраторам, без обоих — строки нет, сбой доставки, очистка.
