# 16-01: миграция 00011 и хранилище заявок, предложений и метрик

Основа: `16-SCHEMA.md` (утверждён 2026-10-14), `16-UX-CONTRACT.md` (Q-1, Q-4, Q-5, Q-7), `16-CONTEXT.md` (D-02…D-05, D-08, D-12). Владелец: «начинай с 16-01» (2026-10-14). Бот (экраны, кнопки, команды) в план не входит — 16-02…16-04.

## Задачи

1. **Миграция.** `migrations/00011_reports.sql` — блок SQL из `16-SCHEMA.md` без изменений; проверка побайтного совпадения с блоком документа. Тест миграций вверх и вниз — по образцу существующих.
2. **Тестовая очистка.** `internal/store/storetest/storetest.go`: `error_reports`, `start_suggestions`, `suggest_awaiting` в `TRUNCATE`.
3. **Заявки об ошибках (`internal/store`).** Принять заявку: корневое событие; повтор пары «пользователь — событие — причина» → отдельный результат без строки; предел 10 за 24 часа (Q-1) → отдельный результат без строки; иначе вставка. Удалить заявку при сбое отправки. Время — по часам вызывающего.
4. **Предложения.** Поставить отметку «жду ссылку» на 10 минут (Q-7), снимая отметку поддержки и ожидание города; взять отметку под блокировкой строки (истёкшая — не действует); предел 3 за 24 часа; вставка с `RETURNING id`; удаление по `id` при сбое отправки. Вход в поддержку, `StartUser` и постановка ожидания города снимают `suggest_awaiting`.
5. **Метрики `/quality`.** Чтение по запросам 1–4 `16-SCHEMA.md`: события по источнику и виду спорта (уникальность — по Q-5: только записи одного источника), последний прогон по источнику (существующий `LatestFinishedRuns`), создано и изменено за 30 дней, заявки по причинам и число предложений за 30 дней. Доли полноты (D-03) — в Go через `event.DateTBD` и `event.ValidURL`, без второй реализации в SQL: функция сводки, которую позже вызовет `/quality`.
6. **Очистка.** Удаление заявок и предложений старше 90 дней (Q-4) — функция хранилища; вызов из служебного шага бота — в 16-02.
7. **Тесты** на тестовой базе: каждая ветка задач 3–6, включая повтор, предел, истёкшую отметку, взаимоисключение режимов, слитое событие, уникальность по Q-5.

## Проверки

`go vet ./...`, `gofmt -l`, полный прогон с `TEST_DATABASE_URL`: прежние 512 PASS, 0 FAIL, 0 SKIP плюс новые. Эталоны экранов не меняются.

Экраны и команды бота, Mini App, выкат.
