# 16-05: лесное оформление Mini App

Основа: `16-DESIGN-CONTRACT.md` (утверждён 2026-10-14, Q-D1…Q-D5 — рекомендованные варианты, компактная шапка главной). Владелец: «Продолжай» (2026-10-14).

## Задачи

1. Палитра раздела 3 (тёмно-зелёная, всегда тёмная по Q-D1), переменная `--accent-ink`, типографика раздела 4.
2. Шапка главной по разделам 6.1 и 7: компактная, фон из трёх слоёв (затемнение, `url(/hero.webp)`, `--hero-fallback`), без файла — градиент; файл `hero.webp` в этом плане не добавляется (Q-D5).
3. Главная: круглые кнопки видов спорта, «Ближайшие старты» из 5 строк и «Весь каталог →» вместо плиток (Q-D4); слоган в шапке (Q-D3).
4. Строка старта (раздел 5), карточка старта без фото с плашкой даты (Q-D2), нижняя панель, остальные экраны — по разделу 6.
5. Тесты раздела 9: `TestStaticSources` разрешает `.webp` с проверкой заголовка RIFF/WEBP и размера ≤ 204 800 байт; `TestStatic` для `/hero.webp` пропускается, пока файла нет. Запреты прежние: без `innerHTML`, `eval`, `initDataUnsafe`, inline-стилей; `localStorage` только в `filters.js`; CSP не меняется.
6. Проверка в браузере без Telegram (headless, 390 px и 1280 px) — снимки главной, каталога, карточки, фильтров, календаря, избранного, профиля для владельца.
