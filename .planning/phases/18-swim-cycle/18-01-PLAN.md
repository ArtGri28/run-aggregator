# 18-01: образцы и контракт экранов плавания и велоспорта

Основа: `18-CONTEXT.md` (D-01…D-07, решения владельца 2026-10-19). Образец формы — `13-UX-CONTRACT.md` и план 13-01. Код, тесты, эталоны экранов и миграции в этом плане не меняются.

## Задачи

1. **Образцы Tristyle.** Сохранить список `specialization=swimming` и `specialization=cycling` (только Беларусь) и страницы событий — по 2–3 на вид спорта, включая зарубежный заплыв и событие с заплывом на время, если такое есть. Только чтение публичных страниц, не больше десяти запросов, пауза между запросами не меньше пяти секунд. Из файлов убираются скрипты, комментарии разметки, токен формы, имена и аватары пользователей. Раздел «Плавание и велоспорт» в `testdata/README.md`: адреса, файлы, SHA-256, факты по каждому событию (дата, страна, дистанции, дисциплина по названию).
2. **Образец MyRace.** Из сохранённого ответа API от 2026-10-14 (вне репозитория, без токена) взять событие только плавания и событие только велоспорта. Таких событий в ответе нет, поэтому виды спорта у двух записей правятся вручную; в README это помечено как изменение. Смешанные события с бегом остаются беговыми (D-02) — для них берётся одна запись как проверка.
3. **Контракт `18-UX-CONTRACT.md`** по образцу контракта фазы 13:
   - справочник: коды дисциплин и подписи, корзины D-03 с границами;
   - главное меню с четырьмя видами спорта по два в ряд и с тремя видами (без велоспорта при пустом каталоге);
   - для каждого вида: сводка, дистанция, дисциплина, список, карточка, пустая выдача; тексты нейтральные, «старт» вместо «забег»;
   - Mini App: круглые кнопки видов спорта, значки плавания и велоспорта, фильтры дистанции и дисциплины;
   - сценарии с S-57 и имена тестов; таблица изменяемых существующих эталонов с точной заменяемой строкой;
   - требования SWC-01… как предложение владельцу; вопросы Q-1… с рекомендацией и альтернативой;
   - раздел «Не входит».
4. **Чек-листы `18-ACCEPTANCE.md`:** локальная приёмка (бот и Mini App), production-приёмка, проверка «до и после»: бег и лыжи, слияния и `users` не меняются.
