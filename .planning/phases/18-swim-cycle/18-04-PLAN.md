# 18-04: источники SwimRocket, Swimcup, cyclingrace.ru и o-time

Основа: `18-SOURCES.md` (проверка 2026-10-19), решения владельца «утверждаю … пункты 2–3», «Начинай с 18-04», «SwimRocket и o-time подключай, письменное разрешение есть» (2026-10-19). SwimRocket заменяет отдельный адаптер X-WATERS: его календарь содержит все российские старты X-WATERS с датой, городом, дистанциями и ссылкой — один запрос за прогон вместо ~21 и без пар-дублей между двумя источниками. Разрешения SwimRocket и o-time записываются в `SOURCE-PERMISSION-LETTERS.md` (дата, суть) до выката. Плавание и велоспорт в справочнике остаются выключенными: события собираются, но не показываются до 18-03. Экраны и эталоны бота не меняются.

## Задачи

1. **Образцы.** Только чтение публичных страниц, не больше 12 запросов на все четыре сайта, пауза не меньше 5 с, честный User-Agent проекта. Из файлов убираются скрипты, комментарии, формы входа и регистрации, данные пользователей.
   - SwimRocket: страница `/calendar/` (записи встроены в страницу).
   - Swimcup: список `/series/` (он даёт название, дату, город, дистанции и ссылки — страницы стартов не нужны); адреса с параметрами и `detail.php?ID=` закрыты в `robots.txt` и не запрашиваются.
   - cyclingrace.ru: страница календаря.
   - o-time: страница `/calendar` (кодировка windows-1251) и, если для вида спорта нужна, одна страница старта.
   README каждого образца — таблица фактов по каждому старту; эталон разбора `*.golden.json` — по таблице, а не по выводу.
2. **Адаптер `swimrocket`.** Один запрос за прогон; записи календаря на странице. Берутся будущие заплывы; не берутся старты за рубежом (поле страны и место). Вид спорта — плавание, дисциплина — открытая вода (календарь «заплывов на открытой воде»). Дистанции — из поля дистанций в метрах; ссылка на событие — сайт организатора.
3. **Адаптер `swimcup`.** Один запрос списка за прогон. Год — из названия («Крылатское 2027»), без года — ближайшая будущая дата с этим днём и месяцем. Один старт в нескольких сериях (Детская лига, ФВВСР) — одна запись по ссылке «Подробнее». Дисциплина: «Открытая вода» и ФВВСР — открытая вода; «Минуты», «Индор», «Спринт» — бассейн. Заплывы на время («60 мин») и эстафеты дистанций не дают (D-05). Страна — Россия. Ссылка на регистрацию (reg.place) показывается, с reg.place ничего не читается.
4. **Адаптер `cyclingrace`.** Календарь гонок; вид спорта — велоспорт; дисциплина — по словам раздела 3 контракта (трек — `other`). Страна — Россия.
5. **Адаптер `otime`.** Календарь всех регионов; вид спорта — по значку старта (бег, лыжи; соответствие значков — по образцу), неизвестный значок — старт пропускается. Регион и город — из карточки. Ссылка на страницу старта на o-time.
6. **Регистрация источников** в `newSources`, подписи в карточке: «SwimRocket», «Swimcup», «CyclingRace», «O-time». Миграций нет.
7. **Тесты:** разбор образцов против эталонов; отсев зарубежных и прошедших стартов, неизвестного вида спорта у o-time; год у Swimcup на стыке годов; одна запись на старт в нескольких сериях; один запрос Swimcup за прогон; ошибка списка — ошибка прогона, неполный набор не возвращается; виды спорта выключены — бот этих событий не показывает.
8. **`deploy/README.md`:** раздел выката новых источников — первые прогоны со статусом `suspect` и их принятие владельцем; беговые старты o-time дадут пары-кандидаты с ПроБЕГом и Марафонцем — решение по ним в `/dupes` у владельца; `events_merged`, `users` и автослияние без изменений.
