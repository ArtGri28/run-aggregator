## Тестовая PostgreSQL (FND-05)

| Option | Description | Selected |
|--------|-------------|----------|
| У меня уже есть локальный Postgres | Тесты читают DSN из переменной окружения (например TEST_DATABASE_URL); если она не задана, интеграционные тесты пропускаются (t.Skip), юнит-тесты normalize идут всегда. Без новых файлов инфраструктуры. | |
| Минимальный docker-compose для тестов | Отдельный docker-compose.test.yml (только postgres:17, без bot/worker) воспроизводим и одинаков у владельца и у исполнителя задач. Отдельён от продакшн Docker Compose из MVP §10.2 (Phase 6). | ✓ |
| Другое | Свой вариант (testcontainers-go, общий staging Postgres и т.п.) | |

**User's choice:** Минимальный docker-compose для тестов
**Notes:** Отдельный файл от production-состава §10.2, который появится только в Phase 6.

## Объём healthcheck в этой фазе

| Option | Description | Selected |
|--------|-------------|----------|
| Заглушка: только exit 0 | Самая простая реализация для закрытия FND-01 (подкоманда существует). Ничего не проверяет, полезна только для Docker HEALTHCHECK-синтаксиса. | |
| Реальная проверка БД уже сейчас | Подключается к PostgreSQL (SELECT 1 через pgxpool), выходит 0/1. Полезна сразу для Docker Compose healthcheck и ручной проверки; heartbeat-таблица из MVP §11 подключается позже (Phase 6). | ✓ |

**User's choice:** Реальная проверка БД уже сейчас
**Notes:** Heartbeat-таблица и мониторинг/алерты (MVP §11) остаются в Phase 6, здесь не реализуются.

## Начальный словарь городов

| Option | Description | Selected |
|--------|-------------|----------|
| Минимальный: из утверждённых источников | Только города/области, реально встречающиеся у Марафонца и ПроБЕГ (по снимкам Phase 1), плюс очевидные синонимы (СПб/Питер/Санкт-Петербург). **User's choice:** Минимальный: из утверждённых источников
