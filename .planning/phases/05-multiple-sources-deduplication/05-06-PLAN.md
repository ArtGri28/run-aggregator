- DDP-07: отклонение блокирует пару по корням (реализовано в store и `Pass`, 05-05); бот только вызывает `RejectCandidate`. Пропущенный кандидат остаётся `pending` и возвращается через [С начала] или следующую команду `/dupes`.

- Бот берёт конфигурацию слияния из `b.Runner.Fold`; без `Runner` (тесты, будущие режимы) слияние из бота недоступно, отклонение работает.
