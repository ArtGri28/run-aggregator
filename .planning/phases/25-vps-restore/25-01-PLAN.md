# 25-01: восстановление после потери VPS

**Дата:** 2026-11-16
**Основание:** при смене IP и узла VPS (Варшава → Варшава) сервер бота потерян: бот не отвечает, по прежнему адресу отвечает чужой хост (другой ключ SSH), вернуть сервер нельзя (владелец, 2026-11-16).

## Решения владельца

- **D-01. Хост** — тот же VPS, где работает VPN (AmneziaWG в Docker). Порты 80 и 443 на нём свободны. Риски, которые принимаются: общая память с VPN, перезагрузка хоста обрывает VPN, `host-apply.sh` (обновления, reboot, ufw) затрагивает и VPN — эти шаги только по отдельному решению.
- **D-02. Копия** — `aggregator-2026-11-11.dump.age` из закрытого канала бэкапов (если в канале нет более поздней). Данные после её даты теряются.

## Шаги (каждый шаг на VPS — по отдельному разрешению владельца)

1. **Mac:** `deploy/restore-check.sh` на копии → `RESTORE OK counters=match migration=<n>`. Нужны: запущенный Docker, локальный образ `postgres:17`, путь к ключу `age`, подпись сообщения копии.
2. **Root-консоль:** пользователь `runagg` (своя группа, пароль заблокирован, не в группе `docker`), строка `authorized_keys` с `restrict` для ключа проекта. Sudoers фазы 1 не нужен: `agg-install.sh` ставит свой `runagg-aggregator`.
3. **Mac:** `~/.ssh/run_agg.conf` и `run_agg_known_hosts` — новый адрес и ключ хоста, ключ сверяется с отпечатком из веб-консоли.
4. `ship.sh` → `STOP: не установлены` → однострочник `INSTALL` в root-консоли → `host-preflight` (Compose, часы, контейнеры хоста) → при необходимости `host-apply.sh compose` → `host-verify`.
5. `ship.sh` (образ текущего коммита) → `secrets.sh` (токен бота, `ADMIN_TG_IDS`, `OWNER_CONTACT`) → Mini App (`WEBAPP_SECRET`, `WEBAPP_DOMAIN`, `COMPOSE_PROFILES`) по разделу Phase 15 `deploy/README.md`; `MYRACE_TOKEN` не вводится (MyRace выключен).
6. `preflight` → `deploy` (пустая база, миграции) → восстановление по шагам 3–10 «Аварийное восстановление» `deploy/RUNBOOK.md` (bot и worker остановлены на время `pg_restore`).
7. A-запись `gdestart.ru` → новый адрес, TTL 300. `verify`, сверка счётчиков с подписью копии, проверка бота и Mini App.
8. Бэкап: `host-apply.sh age`, `backup-apply.sh dirs`, `telegram`, `cron`, ручной запуск `backup.sh`, `backup-status`.
