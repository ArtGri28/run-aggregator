# Phase 8 Plan 04: главное меню, навигация, фильтры, подсказки города

## Что сделано

- **Главное меню:** `mainMenu()` — один экран для `/start` (новое сообщение) и кнопки `m` (правка сообщения). `m` версии не несёт, версию для кнопки «Найти забег» читает без записи.
- **Возврат:** в сводке последняя строка «⬅️ Назад» → `m`; в подменю дистанции «Готово» заменено на «⬅️ Назад»; подпись — константа `backLabel`.
- **Подсказки города (P8):** `store.SimilarCities` ищет ещё и по началу названия без учёта регистра (объединение с правилом ключа, без повторов, до 5, по числу событий); ввод короче двух символов — без подсказок. Ответ «не найден»: при подсказках строка «Возможно, вы имели в виду:», всегда кнопка «📍 Выбрать из списка».
- **Тесты сценариев** `TestS01MainMenu` … `TestS08Country` (`internal/bot/scenario_test.go`).
