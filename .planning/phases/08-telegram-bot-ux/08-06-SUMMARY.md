# Phase 8 Plan 06: «Мои настройки» и сброс с подтверждением

**Статус: complete (локально).** Реализованы экраны E-13, E-14 и сценарии S-12, S-13 утверждённого контракта, а также перенесённые из 08-04 кнопка «⚙️ Мои настройки» в главном меню и подтверждение «Сбросить» в поиске. Новых колонок `users` и миграций нет; `setMyCommands` не вызывается. Telegram API не вызывался, VPS и production не затрагивались. Коммит делает владелец.

Выполнялся поверх незакоммиченных изменений 08-04 и 08-05 (`plan_head_before` — последний коммит владельца `6fcdada`).

## Что сделано

- **Кнопки** (`callback.go`): `s:o:v<N>` — настройки; `s:r:<o|f>:v<N>` — спросить сброс; `s:y:<o|f>:v<N>` — подтвердить; `o`/`f` — откуда пришли (настройки/поиск). `f:x` без поля больше не кнопка.
- **Экраны** (`settings.go`): «⚙️ МОИ НАСТРОЙКИ» — пять строк теми же подписями, что в поиске, страна показывается всегда; кнопки «✏️ Изменить фильтры», «🔄 Сбросить настройки», «⬅️ Назад». Подтверждение: «✅ Да, сбросить» и «⬅️ Назад» (отмена — туда, откуда пришли).
- **Сброс** — изменение данных: только актуальной кнопкой через `updateAt` (проверка версии и запись в одной транзакции); после сброса — экран, с которого пришли, и уведомление «Настройки сброшены»; если настройки уже по умолчанию, версия не растёт.
- **Навигация `s:o` и `s:r`** — по правилам раздела 5: из старого сообщения работают без записи.
- **Главное меню** — вторая кнопка «⚙️ Мои настройки»; **поиск** — «🔄 Сбросить» ведёт к подтверждению.
- `cityName` вынесена из `summary` и используется обоими экранами.
