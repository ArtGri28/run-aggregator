## russialoppet.ru

- **Ценность высокая.** Около 52 лыжных стартов сезона 2027. Почти все новые: лыжи сейчас есть только у Tristyle (5 стартов, Беларусь), лыжный календарь Марафонца ещё не подключён.
- **Блокер — сертификат сайта.** Сервер отдаёт два сертификата: настоящий от Let's Encrypt (ECDSA, до 26.12.2026) и самоподписанный «Bitrix» (RSA). Какой из них придёт, решает выбор шифра. Стандартный клиент Go, которым пользуется сборщик, получает «Bitrix» и обрывает соединение. С VPS, скорее всего, будет так же. Отключать проверку сертификата нельзя. Ограничение шифров при проверке сайта не применялось, страницы `/events/2027/` и событий в этот раз не открывались.
- **Что известно по прошлой проверке (2026-10-08):**
  - один HTML-список `/events/2027/`;
  - в строке дата или диапазон (`12-13.02.2027`), округ, область, город, дистанции со стилем («50/25 км СВ»);
  - признака отмены и переноса нет;
  - API, ленты и iCal не найдено;
  - на каждый день и стиль — отдельная запись («Сокольи Горы» 30.01 и «Сокольи Горы Классика» 31.01).
- **Дубли.** После подключения лыжного календаря Марафонца появятся кандидаты с соседними датами. Их ловит существующее правило «даты отстоят не больше чем на день», автослияние выключено.

## reg.place

- **Доступ.**
  - `robots.txt` сбор разрешает, задержки нет.
  - Документация `/pages/docs/integration` описывает только API регистрации участников. Списка событий там нет.
  - Есть `GET https://api.reg.place/v1/events/<slug>` — одно событие в JSON, без ключа. Поля: название, дата, город, адрес, виды спорта, `stage`, дистанции с датами.
  - Список событий — только HTML-страница `/events`: 12 на страницу, фильтры по виду спорта (`q[sport_id]`) и будущим датам. В строке списка нет года.
- **Состав (56 будущих событий):**
  - плавание около 33, из них около 25 — Swimcup;
  - бег 12;
  - вело 5;
  - лыжи 6, но все шесть — кемпы, а не старты;
  - прочее: шахматы, борьба, гиря, HYROX.
- **Прирост маленький.** Из примерно 44 профильных стартов около 35 уже есть: бег — в ПроБЕГе, плавание — в Swimcup и SwimRocket. Новых около 8: три вело, один бег, три-четыре плавания. Зимой может добавиться лыжа, если организаторы будут регистрировать гонки там.
- **Нагрузка.** Около 5 страниц списка и по одному запросу к API на событие — примерно 60 запросов за прогон.
- **Не берём:** блок организатора (ФИО, телефон, ИНН), заявки (`/heats`), цены, остатки слотов.
- **Риски:**
  - значения `stage` (отмена, перенос) не задокументированы;
  - страны в данных нет;
  - встречаются копии событий со slug `*-copy`;
  - список, похоже, показывает только события с открытой регистрацией.

## Предлагаемые решения

- **D-01. Порядок.** Первым — russialoppet.ru (лыжный сезон впереди, около 52 новых стартов), вторым — reg.place.
- **D-02. russialoppet — доступ.** Публичная страница `/events/<сезон>/` и, при необходимости, страница события. Запросов немного (один список). Стиль КЛ/СВ остаётся в дистанциях текстом. Отдельное хранение стиля — по D-09 Phase 13, отдельной миграцией и только с утверждения.
- **D-03. russialoppet — сертификат.** Варианты:
  - (а) владелец сайта убирает самоподписанный сертификат «Bitrix» или заменяет его настоящим — чисто, без изменений у нас;
  - (б) клиент для этого одного источника предлагает только шифры ECDSA. Проверка сертификата остаётся полной, но решение ломается, если сайт сменит сертификат;
  - (в) ждать (а), а пока делать reg.place.
- **D-04. reg.place — доступ.** Slug — из HTML-списка по видам спорта (бег 1, триатлон 2, акватлон 3, дуатлон 4, вело 5, плавание 6, лыжи 7). Подробности — из JSON API, по одному запросу на событие, с паузой. Кемпы, онлайн-гонки и прочие виды отсеиваются. Страна — RU.
- **D-05. Атрибуция.** Как у остальных источников: в карточке — ссылка на страницу события на сайте-источнике.
- **D-06. Миграции.** Не нужны: источники добавляются как у Phase 17 и 18 (запись источника в коде, без изменения схемы). Если появится потребность в схеме — текст на утверждение отдельно.

## Проверка и решение 2026-10-20 (заменяет Q-2 (в))

- Проверка по разрешению владельца («Разрешаю, проверь»): два запроса с паузой 15 с, клиент Go с TLS 1.2 и только шифрами ECDHE-ECDSA, проверка сертификата полная.
  - `robots.txt` — 200: `/events/` не закрыт, `Crawl-delay` нет.
  - `/events/2027/` — 200, 271 КБ.
  - Сертификат `russialoppet.ru`, выдан Let's Encrypt (YE1), действует до 2026-12-26.
- **D-07.** Решение владельца 2026-10-20: «Делаем (1), russialoppet первым». Сборщик russialoppet.ru использует отдельный TLS-клиент: TLS 1.2, шифры только ECDHE-ECDSA (AES-GCM, ChaCha20), проверка сертификата полная. Остальные источники не затрагиваются. Если сайт сменит сертификат, это видно как ошибка источника в прогоне. Письмо о сертификате всё равно отправляется; после исправления на стороне сайта ограничение снимается.
- Порядок: russialoppet.ru первым, reg.place вторым.
