## Что покрывает проверка скрытия

### `TestSportVisibility` — восемь запросов хранилища
В каталоге беговое событие (RU, Раменское, шоссе) и пробное с видом спорта `skiing` (BY, Раубичи, стадион). Для каждого запроса проверено: беговое событие на месте, пробного нет; после смены вида спорта пробного на `running` оно есть в каждом запросе.

| Запрос | Как проверяется пробное событие |
|---|---|
| `ListEvents` | id в выдаче |
| `CountEvents` | счётчик 1 против 2 |
| `TopCities` | ключ города в списке |
| `Countries` | страна `BY` в списке |
| `SearchCandidates` | id среди кандидатов поиска |
| `SimilarCities` | ключ города в подсказках — по ключу (`ra`) и по названию («Ра») |
| `CityName` | число событий города 0 против 1 |
| `EventTypes` | тип `track` в списке |

Отдельно: текст `sportVisible` соответствует выражению `^ AND e\.sport IN \('[a-z_]+'(, '[a-z_]+')*\)$`, содержит код каждого включённого вида спорта и ни одного выключенного.

### `TestSportHiddenList` — список и счётчик бота
На базе `seeded`: первая страница списка содержит кнопку первого события и «Найдено: 133»; после `storetest.SetSport(…, skiing)` кнопки нет, «Найдено: 132», `CountEvents` = 132.

### `TestSportHidden` — все экраны и карточка
База `seeded` (события Марафонца, одна страна). Добавлены два пробных события без вида спорта: (а) RU, город «Оймякон» (в фикстуре его нет), тип «Стадион» (в фикстуре его нет), слово «Зимогорье» в названии (по нему до добавления ничего не находится); (б) BY, Гродно. Пробы, каждая выполнена дважды — при виде спорта «бег» (находит) и при `skiing` (не находит):

| Проба | Экран | Запрос хранилища |
|---|---|---|
| страна `BY` в меню страны | `f:k` | `Countries` |
| меню страны совпадает со снятым до добавления (текст и кнопки) | `f:k` | `Countries` |
| экран поиска совпадает со снятым до добавления: нет строки и кнопки страны | `f:s` | `Countries`, `CountEvents` |
| события (а) и (б) в списке по всем странам — пройдены все страницы | `p:<стр>` | `ListEvents` |
| «Найдено: N» в списке: N+2 против N | `p:1` | `CountEvents` |
| город в меню города (при фильтре типа «Стадион») | `f:c` | `TopCities` |
| «Стадион» в меню типа | `f:t` | `EventTypes` |
| событие в результатах текстового запроса по слову названия; при `skiing` ответ совпадает с ответом до добавления («ничего не нашлось») | текст | `SearchCandidates` |
| город в подсказках по началу названия («Оймяк») | текст | `SimilarCities` |
| текст с точным названием города выбирает город фильтром | текст | `CityName` |
| карточка по кнопке из списка `e:<id>:<стр>:v<N>` | карточка | `GetEvent` + проверка в `buildCard` |
| карточка по кнопке из результатов поиска `g:<id>:v<N>` | карточка | то же |

Карточка: при «беге» обе кнопки открывают карточку с названием события; при `skiing` те же кнопки отвечают «Событие больше не доступно» с единственной кнопкой возврата. Затем событие возвращено в «бег» и скрыто (`HideEvent`): ответ на обе кнопки совпадает с ответом при выключенном виде спорта — текст и кнопки.

Не покрыто отдельной пробой на уровне бота: подсказки города проживания в анкете и профиле. Они читают те же `TopCities` и `CityName`, которые закрыты `TestSportVisibility`.

### Проверка того, что тесты ловят поломку
Три пробные правки, каждая возвращена: без фрагмента в `listWhere` падают `TestSportVisibility` (`ListEvents`, `CountEvents`, `TopCities`, `Countries`), `TestSportHiddenList`, `TestSportHidden`; без фрагмента в `futureListed` — `TestSportVisibility` (`SimilarCities` обоими способами, `CityName`, `SearchCandidates`, `EventTypes`) и `TestSportHidden` (меню типа, текстовый поиск, подсказки, выбор города текстом); без проверки в `buildCard` — `TestSportHidden` (обе карточки).
