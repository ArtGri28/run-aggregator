<decisions>
## Implementation Decisions

### MyRace (утверждено 2026-10-14, «утверждаю 1–8»)
- **D-01 Страна.** Фильтр `country` API не используется. Загружается весь календарь; страна берётся из `location.country`, каталог оставляет RU и BY через `allowedCountries`. Событие без страны в каталог не попадает.
- **D-02 Вид спорта.** Событие берётся, если среди его видов спорта есть `running`, `trail-running`, `running-with-obstacles`, `sky-running` или `skysnow`. События только вело, SUP, акватлона, плавания, северной ходьбы и прочего пропускаются.
- **D-03 Тип старта.** `trail-running`, `sky-running`, `skysnow` → `trail`; `running-with-obstacles` → `obstacle`; `running` → `other`. В `road` не переводится: по данным API шоссе от кросса не отличить.
- **D-04 Дистанции.** Километры разбираются из названий активностей существующим разбором текста. Шифры («ARKHYZ 15») и подписи без единиц («Девочки 6-7 лет») не угадываются. Событие без дистанций всё равно показывается.
- **D-05 Ссылка.** Страница события на MyRace (`url`) — ссылка на регистрацию.
- **D-06 Прошедшие и абонементы.** Пропускаются, если дата начала раньше сегодняшней (обычный отсев Prepare).
- **D-07 Токен.** Переменная `MYRACE_TOKEN` в `.env`; пустая — источник не подключается. Токена нет в коде, логах, текстах ошибок, тестах и документах.
- **D-08 Частота.** Как у остальных источников — раз в шесть часов. Не больше 50 страниц за прогон, пауза между страницами — секунда.

### На усмотрение исполнителя
- Как передать заголовок в `Fetcher` (минимальное расширение, без нового пакета).
- Разбивка на файлы внутри `internal/ingest/sources/myrace` по образцу `heroleague`.
- Состав тестового образца: несколько событий из образца, по одному на каждый случай D-01…D-04, две страницы.

</decisions>
