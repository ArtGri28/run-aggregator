## Что есть сейчас

- В Mini App пять вкладок: Главная, Каталог, Календарь (весь каталог по дням), Избранное, Профиль. Профиль показывает число избранного, ответы анкеты и фильтры каталога.
- Фильтры Mini App хранятся только на телефоне (`localStorage`, `filters.js`), а не в боте. Фильтры бота и Mini App независимы.
- Избранное у бота и Mini App общее (`GET /favorites`).
- Сервис webapp работает без токена бота. Поэтому имени бота он не знает и не может ничего отправить в чат.
- Бот не умеет отправлять файлы: `sendDocument` в коде нет.

## Мой календарь

- **D-01. Где.** В профиле Mini App появляется вкладка-переключатель «Профиль | Мой календарь». «Мой календарь» — избранные будущие старты, сгруппированные по месяцам: «Ноябрь 2026» → «08.11 · Гатчина · Гатчинский полумарафон». Нажатие на старт открывает его карточку. Нижняя панель Mini App не меняется.
- **D-02. Выгрузка в календарь телефона — файл `.ics`.** Есть две кнопки:
  - «📅 Добавить в календарь» в карточке старта (бот и Mini App);
  - «📅 Добавить все в календарь» в «Моём календаре».
- **D-03. Как файл попадает в телефон.** Бот присылает `.ics` документом в чат. На iPhone и Android такой файл открывается в календаре кнопкой «Добавить». Из Mini App запрос идёт через очередь исходящих (новый вид строки `ics`), отправляет её бот, как сообщения избранного. Mini App показывает: «Файл придёт в чат с ботом».
- **D-04. Содержимое файла.** Название старта, дата (событие на весь день, у многодневного — до даты окончания), город и место, ссылка на карточку `t.me/<бот>?start=e_<id>` и ссылка на источник. Данных пользователя в файле нет. Старты с датой-заглушкой («дата уточняется») не выгружаются. В «Добавить все» попадают только будущие старты, не больше 50 (это предел избранного).
- **D-05. Повторная выгрузка.** Повторное добавление того же старта в календарь телефона даёт тот же старт: в файле постоянный UID `start-<id>@<бот>`. Как календарь поступит с повтором, решает он сам — тексты ничего не обещают.

## Подписка в Mini App

- **D-06. Где.** В профиле Mini App, блок «Подписка на новые старты» с тем же пояснением, что в боте: раз в неделю, по понедельникам, только если появились новые старты.
- **D-07. По каким фильтрам.** По текущим фильтрам каталога Mini App (вид спорта, страна, город, дистанция, дисциплина), без дат. Сервер переводит их в формат подписки бота. Подписка у пользователя одна, общая для бота и Mini App: подписался в Mini App — в «Мои настройки» бота она видна как «по прежним фильтрам», если фильтры бота другие.
- **D-08. Кнопки.** Без подписки — «🔔 Подписаться по фильтрам каталога». С подпиской — «включена», какие фильтры (теги), кнопки «Обновить по текущим фильтрам» (если фильтры отличаются) и «🔕 Отписаться».
- **D-09. API.** `GET /api/v1/subscription`, `PUT /api/v1/subscription` (тело — фильтры каталога), `DELETE /api/v1/subscription`. Запись проходит через ограничитель записи, как избранное. Проверка `initData` — как у всех маршрутов.

## «Поделиться» в Mini App

- **D-10. Кнопка** «📤 Поделиться» в карточке Mini App: `Telegram.WebApp.openTelegramLink` с той же ссылкой, что у бота (`t.me/share/url?url=…start=e_<id>`). CSP не меняется.
- **D-11. Имя бота для webapp.** Бот при запуске записывает своё имя в базу, а webapp отдаёт его в `GET /meta` полем `bot`. Нет имени — нет кнопки. Нужна маленькая таблица (миграция ниже). Альтернатива — строка `BOT_USERNAME` в `.env` и в `docker-compose.yml`: тогда нужна переустановка пакета (`INSTALL`) и строку вносишь ты.

## Вопросы владельцу

- **Q-1. «Мой календарь» — в профиле Mini App (D-01)** — или также в боте, отдельной кнопкой в «👤 Мой профиль»? Рекомендую только Mini App: там список по месяцам читается лучше. Выгрузку `.ics` из карточки бот получает в любом случае (D-02).
- **Q-2. Файл `.ics` приходит в чат с ботом (D-03)** — или скачивается прямо в Mini App (`Telegram.WebApp.downloadFile`)? Рекомендую чат: работает во всех клиентах, а скачивание в Mini App есть только в свежих версиях Telegram и на iPhone попадает в «Файлы», а не в календарь.
- **Q-3. Подписка календаря** (ссылка `webcal://`, которая сама обновляет календарь при изменении избранного) — не делаем сейчас? Рекомендую не делать: для неё нужна постоянная секретная ссылка на пользователя.
- **Q-4. Подписка в Mini App — одна, общая с ботом (D-07)?** Рекомендую да.
- **Q-5. Имя бота через базу (D-11) или через `.env`?** Рекомендую базу: не нужна ручная правка `.env` и переустановка пакета.
- **Q-6. Схема `00014_app_settings.sql`** — утверждаешь?

## Подписка календаря телефона (Q-3, вариант б)

- **D-12. Ссылка.** У пользователя одна секретная ссылка `https://<домен>/cal/<токен>.ics`, токен — 32 случайных байта. Календарь телефона раз в несколько часов сам перечитывает её и показывает избранные будущие старты с переносами, отменами и новыми добавлениями. В базе хранится только хеш токена (SHA-256): сама ссылка есть только в сообщении бота пользователю.
- **D-13. Как получить.** Кнопка «🔗 Подключить к календарю телефона» в «Моём календаре» бота и Mini App. Бот присылает сообщение со ссылкой и короткой инструкцией: iPhone — «Настройки → Календарь → Учётные записи → Добавить → Другое → Подписной календарь»; Android — Google Календарь на компьютере, «Добавить календарь → По URL». Из Mini App запрос идёт через очередь, как файл `.ics`.
- **D-14. Сброс.** Кнопка «🔄 Новая ссылка»: старая сразу перестаёт работать, бот присылает новую. Удаление ссылки — кнопка «Отключить»: строка удаляется, ссылка не работает.
- **D-15. Что видит владелец ссылки.** Только список избранных будущих стартов: название, дата, место, ссылки на карточку и источник. Ни Telegram ID, ни имени, ни анкеты. Тексты бота говорят прямо: «Кто получит эту ссылку, увидит ваши избранные старты. Если ссылка попала не туда — нажмите «Новая ссылка»».
- **D-16. Сервер.** Маршрут без `initData` (календарь телефона заголовок не передаст): неизвестный токен — 404 без подробностей. Ограничение частоты на маршрут. В лог идут только шаблон маршрута, код ответа и время — токена в логах нет; Caddy запросы не пишет (в `docker-compose.yml` нет `--access-log`). Ответ с `Cache-Control: private, max-age=3600`.
- **D-17. Хранение.** В BOT-08 и PROJECT.md: «для подписки календаря — Telegram ID, хеш ссылки и время создания». Ссылка удаляется кнопкой «Отключить».
- **Риски:**
  - Google Календарь на Android не умеет добавлять календарь по ссылке в приложении — только на компьютере, на calendar.google.com;
  - телефоны перечитывают ссылку сами, от нескольких минут до суток, — перенос появится не сразу. Тексты не обещают, когда.

### Схема — расширенная (миграция `00014_app_settings.sql`, файл не создан)

К утверждённой таблице `app_settings` добавляется вторая:

```sql
-- +goose Up
CREATE TABLE app_settings (
    key   TEXT PRIMARY KEY CHECK (key ~ '^[a-z][a-z_]{1,31}$'),
    value TEXT NOT NULL CHECK (char_length(value) <= 200)
);

CREATE TABLE calendar_feeds (
    tg_id      BIGINT PRIMARY KEY CHECK (tg_id > 0),
    token_hash BYTEA NOT NULL UNIQUE CHECK (octet_length(token_hash) = 32),
    created_at TIMESTAMPTZ NOT NULL
);

-- +goose Down
DROP TABLE calendar_feeds;
DROP TABLE app_settings;
```
