# Phase 21: UX-контракт «Мой календарь», подписки и «Поделиться» в Mini App

**Статус:** утверждён владельцем 2026-10-20: «Контракт утверждаю, Q-1 (а), Q-2 по рекомендации». Часть 1 — бот (K-1…K-5), файлы и подписной календарь, S-67…S-69; часть 2 — Mini App (A-1…A-4), S-70.
**Основа:** `21-CONTEXT.md` (D-01…D-17, ответы владельца 2026-10-20), `20-UX-CONTRACT.md` (подписка, «Поделиться»). Обозначения — как в `13-UX-CONTRACT.md`: тексты HTML; `[подпись] → data`; ряды через ` | `; `url:` — кнопка-ссылка.

Каталог тестов — Марафонец, «сегодня» 2026-09-29. `{bot}` — имя бота (в тестах `test_bot`), `{domain}` — домен Mini App (в тестах `app.test`), `{token}` — токен ссылки календаря.

## 1. Принципы

1. Тексты не обещают, когда календарь телефона подтянет изменения, и ничего не говорят о данных пользователя, кроме предупреждения о ссылке (D-15).
2. Экраны поиска, списков, меню, анкеты и настроек не меняются. Меняются карточка (кнопка «📅 В календарь») и «👤 Мой профиль» (кнопка «📅 Мой календарь»). Полный список — раздел 7.
3. Файл и подписка календаря — только избранные будущие старты. Старт с датой-заглушкой («дата уточняется») в файл и в подписку не попадает, а в списке «Мой календарь» показывается с этой пометкой.

## 2. Callback бота

Новая буква `k:` (календарь), без версии фильтров — фильтры не меняются:

| data | Действие |
|---|---|
| `k:o` | экран «📅 Мой календарь» (правкой сообщения) |
| `k:f` | файл всех стартов `.ics` новым сообщением |
| `k:e:{id}` | файл одного старта `.ics` новым сообщением |
| `k:l` | ссылка подписки календаря: создать (если нет) и прислать |
| `k:r` | новая ссылка: старая перестаёт работать, новая — новым сообщением |
| `k:x` | отключить ссылку: строка удаляется |

## 3. Экраны бота

### K-1 «👤 Мой профиль» — кнопка календаря

Над «⬅️ Назад» — ряд `[📅 Мой календарь] → k:o`. Остальное без изменений.

### K-2 «📅 Мой календарь»

Избранные будущие старты по месяцам, по дате:
```
📅 <b>Мой календарь</b>

<b>Октябрь 2026</b>
02.10 · Чулково · Кросс памяти Серафима и Георгия Знаменских
03.10 · Екатеринбург · Трейл «Шарташ Карасики»

<b>Ноябрь 2026</b>
08.11 · Гатчина · Гатчинский полумарафон
---
[📅 Добавить все в календарь телефона] → k:f
[🔗 Подключить к календарю телефона] → k:l
[⭐ Избранное] → w:o
[⬅️ Назад] → u:o
```
Строка старта — как кнопка списка (`eventBtn`): дата, город, название, значок небегового вида спорта. Пусто:
```
📅 <b>Мой календарь</b>

Здесь пока пусто. Добавьте старты в избранное — они появятся здесь по датам.
---
[⭐ Избранное] → w:o
[⬅️ Назад] → u:o
```

### K-3 Файл всех стартов (`k:f`)

Документ `starts.ics` новым сообщением, подпись:
```
📅 Избранные старты: {n}. Откройте файл и нажмите «Добавить».
```
Нет стартов с точной датой — только уведомление «Нет стартов с точной датой».

### K-4 Карточка — кнопка «📅 В календарь»

Под рядом «⭐ … | 📤 Поделиться» — ряд `[📅 В календарь] → k:e:{id}`. У старта с датой-заглушкой кнопки нет. По нажатию — документ `start-{id}.ics` новым сообщением с подписью «📅 Откройте файл и нажмите «Добавить».». Старт недоступен — уведомление «Событие больше не доступно».

### K-5 Ссылка подписки календаря (`k:l`, `k:r`)

Новым сообщением:
```
🔗 <b>Календарь телефона</b>

Подключите эту ссылку в календаре телефона — он сам будет подтягивать старты из избранного:
https://{domain}/cal/{token}.ics

iPhone: Настройки → Календарь → Учётные записи → Добавить учётную запись → Другое → Подписной календарь.
Android: Google Календарь на компьютере → «Другие календари» → «+» → «Добавить по URL».

Кто получит эту ссылку, увидит ваши избранные старты. Если ссылка попала не туда — нажмите «Новая ссылка».
---
[🔄 Новая ссылка] → k:r
[🚫 Отключить] → k:x
```
- Ссылка уже есть и нажата `k:l` — ссылку нельзя показать снова (хранится только её отпечаток), поэтому сообщение:
```
🔗 <b>Календарь телефона</b>

Ссылка уже выдана — она в одном из сообщений выше. Если не найти — нажмите «Новая ссылка».
---
[🔄 Новая ссылка] → k:r
[🚫 Отключить] → k:x
```
- `k:r` — уведомление «Старая ссылка больше не работает» и сообщение K-5 с новой ссылкой.
- `k:x` — уведомление «🚫 Ссылка отключена», у сообщения пропадает клавиатура.
- Домен не задан (Q-1) — кнопки «🔗 Подключить…» в K-2 нет.

## 4. Подписной календарь (`GET /cal/{token}.ics`)

- Без `initData`; неизвестный или отключённый токен — 404 с телом `not found`.
- `Content-Type: text/calendar; charset=utf-8`, `Cache-Control: private, max-age=3600`.
- Календарь `X-WR-CALNAME:Где старт? — избранное`, `REFRESH-INTERVAL;VALUE=DURATION:PT6H`.
- Событие: `UID:start-{id}@{bot}`, `DTSTART;VALUE=DATE` и `DTEND;VALUE=DATE` (день после последнего дня), `SUMMARY` — название с пометкой «[ОТМЕНЁН]»/«[ПЕРЕНЕСЁН]», `LOCATION` — город и место, `URL` и `DESCRIPTION` — ссылка на карточку `https://t.me/{bot}?start=e_{id}` и на источник.
- Предел — 30 запросов в минуту на токен; сверх — 429.
- В логе: шаблон маршрута, код, время. Токена нет.

Файл `.ics` из K-3 и K-4 — тот же формат без `REFRESH-INTERVAL`.

## 5. Mini App

### A-1 Профиль — вкладки

Под заголовком профиля — переключатель «Профиль | Мой календарь» (`#/profile`, `#/profile/calendar`). Вкладка «Профиль» — прежний экран и ниже блок подписки (A-3).

### A-2 «Мой календарь»

Избранные будущие старты по месяцам: заголовок месяца «Октябрь 2026» и строки, как в избранном (сердечко убирает старт). Ниже кнопки:
- «📅 Добавить все в календарь телефона» → `POST /api/v1/calendar/file`; ответ — подсказка «Файл придёт в чат с ботом»;
- «🔗 Подключить к календарю телефона» → `POST /api/v1/calendar/link`; подсказка «Ссылка придёт в чат с ботом».

Пусто — «Здесь пока пусто. Добавьте старты в избранное — они появятся здесь по датам.» и кнопка «К каталогу».

### A-3 Подписка на новые старты

Блок в вкладке «Профиль»:
- без подписки — текст пояснения из N-3 (Phase 20), теги текущих фильтров каталога и кнопка «🔔 Подписаться по фильтрам каталога» → `PUT /api/v1/subscription`;
- с подпиской — «🔔 Подписка на новые старты: включена», пояснение из N-4, теги фильтров подписки; если фильтры каталога другие — «по прежним фильтрам» и кнопка «Обновить по фильтрам каталога»; кнопка «🔕 Отписаться» → `DELETE /api/v1/subscription`.

### A-4 Карточка

Под кнопкой избранного — «📅 В календарь» (`POST /api/v1/calendar/file?event={id}`, подсказка «Файл придёт в чат с ботом»; у даты-заглушки кнопки нет) и «📤 Поделиться» (`Telegram.WebApp.openTelegramLink` со ссылкой из N-1 Phase 20; нет имени бота в `meta` — кнопки нет).

### API

| Маршрут | Ответ |
|---|---|
| `GET /meta` | новое поле `bot` — имя бота или `""` |
| `GET /subscription` | `{"on":false}` либо `{"on":true,"filters":{…как фильтры каталога…}}` |
| `PUT /subscription` | тело — фильтры каталога (`sport`, `country`, `city`, `dist`, `type`); 204 |
| `DELETE /subscription` | 204 |
| `POST /calendar/file[?event={id}]` | 202 — строка очереди создана; 404 `gone`; 409 `empty` — нет стартов с точной датой |
| `POST /calendar/link` | 202; 409 `no_domain`, если домен не задан |

Запись — через ограничитель записи. Отправку делает бот из очереди: новые виды строк `ics` (файл) и `cal_link` (ссылка). Одна ожидающая строка на пользователя и вид — повторное нажатие до отправки строки не добавляет.

## 8. Требования (предложение)

- **CAL-01:** «Мой календарь» в боте и Mini App — избранные будущие старты по месяцам. Критерий: S-67, тесты Mini App.
- **CAL-02:** Файл `.ics` одного старта и всех — документом в чат; без данных пользователя; без дат-заглушек. Критерий: S-68, S-70.
- **CAL-03:** Подписной календарь по секретной ссылке; в базе только хеш; новая ссылка отменяет старую; отключение. Критерий: S-69.
- **CAL-04:** Подписка на новые старты в Mini App — одна, общая с ботом. Критерий: тесты `webapp`.
- **CAL-05:** «Поделиться» в Mini App. Критерий: тесты `webapp`, просмотр.
- **CAL-06:** В логах нет токена ссылки, Telegram ID и названий; BOT-08 описывает хранимое. Критерий: тесты логов.

## 9. Вопросы владельцу

- **Q-1. Домен для ссылки календаря.** Сейчас домен Mini App знает только Caddy: бот и webapp его не получают. Варианты:
  - **(а)** передать боту `WEBAPP_DOMAIN` из того же `.env` через `docker-compose.yml`. Нужна переустановка пакета: одна команда `INSTALL` в root-консоли при выкате. Новых строк в `.env` нет;
  - **(б)** webapp запоминает домен из первого запроса Mini App и пишет его в `app_settings`. Без `INSTALL`, но неявно.
  
  Рекомендую (а): явно и проверяемо.
- **Q-2. Выкат двумя частями:** 1) календарь в боте, файлы `.ics`, подписной календарь; 2) Mini App — вкладки, «Мой календарь», подписка, «Поделиться». Рекомендую двумя частями: каждая меньше и проверяется отдельно.

## 10. Не входит

- напоминания в календаре телефона;
- общие фильтры бота и Mini App;
- скачивание файла внутри Mini App.

## 11. Решение 2026-10-20: подписка из Mini App без вида спорта

Владелец выбрал вариант (а): «А». Если в фильтрах каталога Mini App вид спорта не выбран, подписка идёт по всем видам спорта. В копии фильтров это `"all": true`, поиск бота это поле не читает.

- Сообщение N-5 (Phase 20) у такой подписки: вместо строки вида спорта — «🏅 Все виды спорта». У небегового старта перед названием значок вида спорта, как в избранном. Эталон — `s63_digest_all`.
- «🔎 Показать все в поиске» переносит в поиск бота страну и город без «всех видов спорта»: поиск бота ищет по одному виду спорта.
- В блоке подписки Mini App такой подписке соответствует тег «Все виды спорта».
- Фильтры подписки передаются параметрами адреса, как у `GET /events`, а не телом запроса.
- `POST /calendar/link` не отвечает `409 no_domain`: webapp не знает домена. Без домена бот закрывает строку очереди и ничего не шлёт.
